User expects code reviews written from the perspective of a senior Automation Lead peer. Direct, technically precise, no abstract descriptions.

**Why:** User is an experienced automation engineer who finds vague feedback unhelpful and wants to act on findings immediately.

**How to apply:** Every critical and major finding must include a before/after code snippet showing exactly what to change. Call out good patterns explicitly — this reinforces what to keep. Do not pad with qualifiers. If something will break tests silently, say so plainly.
